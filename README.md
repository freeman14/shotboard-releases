# Shotboard for macOS

An infinite canvas for AI images and video.

**[Download the latest version](https://github.com/freeman14/shotboard-releases/releases/latest)**: pick the `.dmg`
for your Mac, `arm64` for Apple Silicon (M1 and later) or `x64` for Intel. Requires macOS 14 or later.

Shotboard updates itself: when a new version is ready, click **Restart to update** in the titlebar.

This repository only hosts releases.
